# Eshop - Multi-Vendor E-Commerce Platform

A full-stack multi-vendor e-commerce platform built with the MERN stack.

## Features

- User authentication
- Seller registration and authentication
- Admin functionality
- Product management
- Event management
- Shopping cart
- Wishlist
- Coupon system
- Order management
- Stripe payment integration
- Seller dashboard
- Withdraw requests
- User-seller conversations
- Real-time messaging support

## Technologies

- MongoDB
- Express.js
- React.js
- Node.js
- Redux
- Stripe
- Socket.IO
